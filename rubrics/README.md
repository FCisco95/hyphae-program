# Rubrics

Every rubric a Hyphae community scores against is published here, versioned. A community's `rubric_version` points at one of these files, and each reward epoch pins the rubric it was scored under.

| File | Status |
|---|---|
| `mycel-1.0.0.json` | Superseded. |
| `mycel-1.1.0.json` | Superseded: the "never" list is scoped to a specific coin. |
| `mycel-1.2.0.json` | **Live**: MYCEL scores under it today. |
| `mycel-1.3.0.json` | Candidate, not applied: grounded, uncertain price speculation is allowed; guarantees, "buy" or "hold" instructions and unsupported hype still earn zero. |

An AI grades each contribution against the live rubric and shows its reasoning. A breach of the rubric's "never" list credits zero whatever the score; that rule runs in code, after the model answers.
